# Plan de especificaciones

Las specs se crearán progresivamente antes de cada implementación, siguiendo TRD §18 y §19.

| Orden | Archivo previsto | Alcance | Estado |
|---|---|---|---|
| 001 | `001-contratos-configuracion.md` | Esquemas, tipos, validación y configuración canónica | Pendiente de redactar |
| 002 | `002-grafo-semillas.md` | Grafo multicapa, derivación de semillas y hashes | Pendiente de redactar |
| 003 | `003-motor-seir.md` | Transiciones diarias e invariantes | Pendiente de redactar |
| 004 | `004-politicas-comparacion.md` | Elegibilidad, presupuesto y comparación pareada | Pendiente de redactar |
| 005 | `005-agregacion-reproduccion.md` | Métricas, exportación y reproducción | Pendiente de redactar |

Cada spec debe incluir RF/CA, alcance, entradas/salidas, ejemplos, casos límite, pruebas TDD y criterio de terminado. Los nombres listados son planificación, no enlaces a archivos existentes. API, UI e infraestructura se especificarán en incrementos posteriores.
