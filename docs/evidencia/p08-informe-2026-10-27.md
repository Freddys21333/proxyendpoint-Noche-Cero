# P-08 · Informe para alcaldía · 2026-10-27

Estado: verificado localmente en modo ficticio. Contrato: [P-08](../../specs/p08-report.md). No acredita T-22, predicción epidemiológica, aceptación humana integral ni despliegue.

## Implementación

- Python: `simulation/report.py`, `api/report.py`; ReportLab 5.1.0 fijado en lock, pypdf 6.21.3 como dependencia de pruebas.
- `POST /v1/reports/mayor`: entrada `CompareResponse` completo, hasta 32 MiB; PDF binario como adjunto; errores JSON saneados. El servidor local conserva 64 KiB para configuración/preview/compare.
- `scripts/report_mayor.py`: generación desde JSON sin servidor; rechaza reemplazar el archivo fuente.
- Botón en Comparación junto a exportaciones y en resultado completo de trabajos PRO. Generación, error/reintento y cancelación al desmontar/cambiar resultado; respeta `VITE_API_BASE_URL`.
- Esquema, hashes, progreso y agregados se comprueban sin volver a simular. Recomendación derivada del backend, costos del registro diario, P05/P95 separado del IC, victorias/empates/pérdidas, anexo de configuración/versiones/hash. Sin LLM, almacenamiento ni credenciales.

- Infectados medios: sin intervención 4,70; aleatoria 3,67; dirigida 3,13.

- Dirigida frente a aleatoria: **7 victorias, 20 empates, 3 pérdidas**; se conservan todas. Es un ejemplo funcional, no la matriz científica.
- PDF final revisado: `.tools/p08-final/report.pdf`, 9.442 bytes, 4 páginas; SHA-256 `5dea36fc4330ad90716071e27004da4492e3a4f2cf0d3f259ef9aaccd84e8782`. Misma entrada y entorno generan mismos bytes. Los campos volátiles del JSON no se inventan ni se escriben en el PDF.
- Se renderizaron todas las páginas con Poppler y se inspeccionaron: tablas, hash, márgenes, paginación y anexo sin recortes. Poppler emitió avisos locales sobre fuentes de sustitución Symbol/ArialUnicode; las páginas renderizadas y extracción no muestran glifos perdidos.

- Prueba de recuperación UI: respuesta 422 inyectada explícitamente para comprobar el mensaje; se retiró la interceptación y se descargó el PDF real al reintentar (`.tools/p08-retry.pdf`). Ese 422 controlado añade un error de red esperado en consola, no evidencia de fallo de la API real. El informe es ficticio, no incorpora observaciones de dengue ni infiere qué parámetros se copiaron de un preset. Declara `manabi-dengue-2025-v1` como recurso separado `fitted-not-validated`; no lo reactiva. Los costos son educativos, independientes de AWS. T-22 y T-13..T-16 permanecen abiertos.
